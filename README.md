# SpiritTech

Интернет-магазин техники для игр, работы и повседневной жизни. Проект выполнен на HTML, CSS и JavaScript.

## Возможности

- Каталог из 11 товаров с фотографиями, названиями и ценами.
- Добавление товара в корзину.
- Изменение количества и удаление товаров внутри корзины.
- Автоматический подсчёт общей стоимости и количества товаров.
- Сохранение корзины в localStorage.
- Форма оформления заказа с именем, фамилией, адресом доставки и телефоном.
- Проверка обязательных полей и номера телефона.
- Адаптивная верстка для компьютеров, планшетов и телефонов.

## Структура проекта

```text
SpiritTech/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── data.js
│   └── script.js
├── images/
└── README.md
```

- `index.html` — разметка магазина, корзины и формы заказа.
- `css/style.css` — оформление, адаптивность и анимации.
- `js/data.js` — данные товаров: идентификаторы, названия, цены и пути к фотографиям.
- `js/script.js` — создание карточек, работа корзины, localStorage и оформление заказа.
- `images/` — фотографии товаров, логотип и иконки.
